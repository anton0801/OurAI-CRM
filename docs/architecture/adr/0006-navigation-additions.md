# ADR 0006 — Additional sidebar entries

Status: accepted (2026-09-24)

## Context
§4.4 lists the sidebar groups Production (Projects, Accounts, Content, Calendar, References,
Library), Operations (OFM, Campaigns, Team) and Insights (Analytics, Finance, Knowledge). The screen
catalogue also defines primary work surfaces that are not reachable from those entries without
extra clicks: Tasks (S27), Partners (S73), Metrics Inbox (S49) and Goals (S53).

## Decision
Add Tasks to Production, Partners to Operations, and Metrics and Goals to Insights. All other entries
and their order follow §4.4. Entries are hidden when the member lacks the module permission.

## Consequences
Two more rows in the sidebar; no screen is only reachable through a deep link.
